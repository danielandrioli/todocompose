## <img src="https://user-images.githubusercontent.com/60299141/158283111-231ef8da-9d0f-4420-96bd-6fc02bf809e4.png" width="25" /> Visão geral
EduTask é um aplicativo para auxiliar alunos e professores na organização das suas tarefas. 

Ele foi criado para a matéria Atividade Extensionista III do curso Engenharia de Software da Uninter.

## <img src="https://user-images.githubusercontent.com/60299141/158274121-e6f063de-29fd-4a90-b9d2-172d98ed0826.png" width="25" /> Tecnologias e bibliotecas utilizadas

- 100% Kotlin
- Arquitetura MVVM
- Jetpack Compose
- [Dagger-Hilt](https://developer.android.com/training/dependency-injection/hilt-android) para injeção de dependência
- [Coroutines](https://developer.android.com/kotlin/coroutines)
- [Room](https://developer.android.com/training/data-storage/room) para o banco de dados
- [DataStore](https://developer.android.com/topic/libraries/architecture/datastore) para armazenamento de preferences
- [StateFlow](https://developer.android.com/kotlin/flow/stateflow-and-sharedflow)
